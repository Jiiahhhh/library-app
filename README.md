# 📚 Library Management System

A simple library management app built with Vanilla JavaScript and OOP principles.

## ✨ Features

- Add and remove books with categories
- Borrow and return books with stock tracking
- Search books by title or author
- Filter books by genre
- Real-time statistics
- Data persisted in localStorage

## 🛠️ Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- ES6 Classes with Private Fields
- Inheritance (EBook extends Book)
- ES6 Modules (import/export)
- localStorage for data persistence
